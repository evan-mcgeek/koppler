    On the board

    A cable: the app at its start calls your local copy of the app at its end. Drag from the ring on a card's edge, or use the card's Cables field.
    Dashed: an app at either end is not running yet
    The light where a cable plugs in: it works, could not be checked, or fails. Click it to test again; drag it to start a new cable.
    A tunnel to a database or cache the app uses
    A queue between apps: dashed while it is the deployed one, solid once its switch runs it locally
    An outside system, such as Firebase: it never runs here
    Protected
    A protected environment (production, usually): red marks only the frame (top rule, banner, Run). Red on the board always means something failed.

        Connect an agent

        Koppler starts and stops a confirmed run by itself. The agent is needed for what it cannot do alone: manual checklists, notes, fixing a failed start, and anything a run leaves over.

        1. 1Open your agent session in this project
        2. 2Run this command there
          /koppler-run connect
        3. 3The dot turns green once it listensAnything sent meanwhile waits for it.
