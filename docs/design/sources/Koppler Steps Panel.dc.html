Steps panel: a flow you can read

Acme Shop, flow "Black Friday discount". The notes are the agent’s, word for word. The summaries and value lists are examples of what the agent would write (section 7).

7

What the agent writes

The panel can only lead with a summary if the agent writes one. Each step’s finding becomes three fields; the app shows whichever exist.

summaryOne sentence, plain words, no class or field names. About 100 characters
valuesA short list of label and value: what is read or written, the flag or setting, dates, classes. Labels are one word
noteEverything else, as now. Kept in full
Older flowsNo summary: the row falls back to the note’s first clause, and the opened row shows the note alone
AskingThe app asks the agent for these fields when it writes or updates a flow
