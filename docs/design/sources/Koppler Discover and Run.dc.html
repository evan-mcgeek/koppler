Discover and Run

Two front doors on one base. Discover is for understanding and sharing a flow; Run is for running a slice of it on this Mac. Acme Shop, the Checkout feature board.

1

The two front doors

Discover | Run is the first control after the mark, in ink, larger than the switches after it: it decides what the rest of the bar is about. Each door keeps its own last board, so switching doors returns you to where you were in that door. Plan and Live become Run’s own switch; Discover has nothing to run, so its bar has no status, Activity, Stop or Run.

Crossing over

In Discover, picking cards (shift-click, or the step’s apps from the panel) brings up one bar: Plan a run with these. It asks whether to make a new run board or add to one, then opens Run on it. The run board remembers the flow it came from, and a Flow chip on its canvas leads back.

Sharing a feature board

Share sits at the right of Discover’s bar on a feature board. It makes a view-only snapshot and copies its link. The viewer opens it in any browser: no install, no sign-in. The page is one self-contained file, so it works the same exported, served by Koppler, or put on the company’s own host.

Comments on a feature board

Comment from a card’s or a step’s right-click menu, or with the Comment button then a click on what it’s about. The thread opens beside it. The agent answers in the thread; a change it makes is drawn dashed on the map and in the steps until you keep it.
