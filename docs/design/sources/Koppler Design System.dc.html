Design system · Patch bay · dark first, three light schemes

Graphite hardware with its labels printed on the panel. Square corners, hairlines. Mono caps only for codes: kind tags, QA and PROD, the PROD banner. Labels and actions are sentence-case sans; values you could copy are plain mono. Colour is a signal: one for what runs locally, one for what still calls the deployed environment, a live colour for running and passed tests, and red for PROD and failures. Mono is the default scheme; four more dark and three light schemes ship in Appearance, and local and deployed can be set by hand.

TruthThe board shows what actually runs. A lit LED means running.
QuietGrey until something needs you. Colour is never decoration.
Loud PRODPROD is red and striped in every scheme, and nobody can change it.
