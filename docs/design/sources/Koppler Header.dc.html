The brief’s questions

What gives way first, in order?1 Settings word. 2 The wordmark. 3 The two status chips merge into one. 4 The Activity word. 5 The stack or board name truncates. In Discover, Ask the agent drops its word at step 3 and Feature board drops at step 4. Below 960 (Discover 900) nothing else shrinks; that’s the bar’s minimum
Do Logs, History, Traces and Credentials stay in the bar?No, in every view. Logs, History and Traces become one Activity menu in Plan and Live, with L still opening Logs. Credentials moves into Settings. Discover shows none of them, because it runs nothing
Can the status chips be shorter?Yes. "Nothing running" becomes "0 running", which says the same and matches "4 running" in Live. "No agent" stays; when connected it reads "Agent". The plug icon goes: clicking the agent chip offers Connect
Widths at 1280Plan needs about 1180 with this layout, leaving roughly 100 px. Measured from the brief’s table, not from the built bar, so check it in code
HelpThe ? button moves into the Koppler menu behind the mark, with keyboard shortcuts. ? on the keyboard still opens it
