2

Type hierarchy

Mono caps are kept for codes: kind tags (.NET, SQS, TUNNEL), the environment (QA, PROD) and the PROD banner. Everything you read as a word is sentence-case sans: field labels, toolbar and header buttons, card footers, section names. Values you could copy (branches, hosts, ports, step counts) are plain mono.

12

Connection test on the socket

The result stays on the socket, because the socket is where you click to run the test: cause and effect in one place. The cable already says running or waiting, so it stays out of it. The fix is how the dot sits: the socket becomes a ring in the local colour with a hole in the board colour, and the result sits in the hole. The dark gap keeps two bright colours from blurring, and each state has its own shape, so none relies on colour alone.
